# Check 红绿灯、多 Fix 与复检流程自测

本条目用于集中检验桌面端核心运行态交互及 GFM Markdown 渲染效果。

## 预期前端视觉核对清单

| 操作阶段 | 侧边栏状态灯预期 | 详情区预期 |
| :--- | :--- | :--- |
| 初始未运行 | 三颗灰色圆点 | 所有命令显示「运行」按钮 |
| 首次点击 `运行 Check` | 第 1 颗绿灯，第 2/3 颗先蓝脉冲后变红灯 | 失败步骤自动展开日志显示中文 `[缺失]` 输出 |
| 点击 `运行 Fix` | 弹出包含 2 条写入命令的确认框 | 无「不再弹窗」复选框，确认标题显示 `Fix` |
| 确认执行 `Fix` 后 | `Fix` 全绿后自动重跑 `Check`，3 颗全变绿 | 验证无额外提示横幅干扰 |
| 点击 `Reset Markers` | `reset-markers` 确认后清理标记 | 再跑 `Check` 恢复 1 绿 + 2 红 |

- 若运行测试时需要隔离临时目录，可通过 `SETTLED_DEMO_DIR` 指定目录。
