# 前端极限态：标签溢出、缺省字段与长日志验证

本条目用于集中核对以下几个历史容易出现排版回归的前端场景：

1. **三处标签溢出行为**：
   - 左侧栏列表卡片：单行自适应容纳，多余折叠为 `+N`，鼠标悬停查看完整列表；
   - 详情信息卡片：紧凑单行展示 `+N` 并支持键盘聚焦弹出气泡；
   - 顶部标签筛选框：选中多个标签后验证最多 4 行自动纵向滚动。
2. **字段兼容细节**：
   - `createAt` 使用 legacy ISO-8601 字符串 `"2026-11-19T12:00:00+08:00"`，验证 `settled-core` 自动解析后在详情区正常显示本地时间；
   - 第 1 条 `check` 使用纯字符串简写且无 `description`，验证日志展开区隐藏多余空白说明。
3. **长日志、ANSI 终端样式与混合红绿灯**：
   - 150 行日志同时覆盖前端日志盒滚动和 CLI 默认 120 行自动截断逻辑；
   - `ANSI 终端色彩` 步骤展示 16/256/TrueColor、Vitest 徽章、跨行 `stdout`/`stderr` 状态隔离、清屏/OSC 控制码剥离及 `\r` 进度覆盖，可切换浅色/深色主题核对对比度；
   - 第 4 条 `check` 固定失败，方便点击总控 Check 后在侧边栏直接看到 `绿-绿-绿-红` 组合灯。
