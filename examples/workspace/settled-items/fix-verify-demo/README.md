# 多步骤修复与复检演练

本条目使用无副作用的临时标记文件（不修改本机系统配置），同时服务于：
- **桌面端交互演练**：`check` 标红 → `fix` 弹窗确认并修复 → 自动复检变绿 → `reset` 恢复未完成状态。
- **CLI 与自动化测试覆盖**：涵盖多步骤并发、`--step` 单步调用、`settled fix` 自动复检、`settled run` 通用执行、字符串简写命令与对象命令混用，以及非零 stderr 失败场景。

> 测试隔离说明：可通过环境变量 `SETTLED_DEMO_DIR` 指定临时标记所在目录（未设置时默认使用系统 `os.tmpdir()`）。
