# Editor & License Migration Notes

Example of a **pure documentation / manual** item without `scripts.check`.

## When Setting Up a New Machine
1. Deactivate single-seat GUI app licenses (e.g., Typora) on the retiring machine before activating on the new device.
2. On macOS: open **System Settings -> Privacy & Security -> Accessibility** and grant permissions to terminal/window tools.
3. Verify external IDE CLI launcher (`code --version`) works from terminal so **Settled** can open item folders directly.
