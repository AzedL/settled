# Multi-Fix & Custom Script Suite

用于集中验证**多个独立 `fix` 步骤**以及**多种形态自定义任务组**的交互与并发行为（所有临时标记均只写入系统临时目录，不会修改工作区或本机环境）。

## 推荐验证场景

1. **部分修复 + 自动复检**：
   - 先点击 `运行 Check`，3 个检查灯会变为红色。
   - 在 `Fix` 分组里只点击单条命令（例如 `Provision alpha marker`），确认弹窗并执行后，系统会自动重跑全部适用 `check`，仅第一盏灯变绿、其余两盏仍为红。
2. **整组并行 `fix`**：
   - 点击 `运行 Fix`，确认弹窗后 3 条 `fix` 会并行执行，完成后自动重跑 `check` 使 3 盏红绿灯全部转绿。
   - 也可在运行 `600ms` 延迟步骤期间点击中止按钮，验证立即中止状态。
3. **多个自定义脚本组**：
   - `Diagnose Env`：验证自定义分组（含对象步骤与纯字符串命令混合格式）的整组/单条执行与日志输出。
   - `Cleanup Markers`：支持只清理 `alpha & beta` 或整组清理全部标记，将条目重新重置回未通过状态。
   - `Simulate Partial Failure`：验证单对象格式的自定义任务失败退出码与 `stderr` 日志展示。
